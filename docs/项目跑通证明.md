## 六、执行命令记录

```bash
# 1. 登录超算
ssh clli_04@swarm01.whu.edu.cn

# 2. 上传代码
cat > ~/project/CODE/rnn_poetry/main.py < local_main.py

# 3. 提交训练（不同epoch）
cd ~/project/CODE/rnn_poetry
sbatch hpc_job.sh                       # Job 2929021 (30ep)
sed -i 's/EPOCHS = 30/EPOCHS = 100/' config.py && sbatch hpc_job.sh  # 2929114

# 4. 查看状态
squeue -u clli_04
tail -f job_2929021.log

# 5. 生成测试
python3 -c "from main import generate,load_vocab,PoetryLSTM; ..."
```

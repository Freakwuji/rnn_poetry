# 武汉大学超算中心使用指南（从零开始）

> 适用环境：Windows 10/11 + PowerShell/CMD
> 用户名：your_hpc_user（请替换为你自己的用户名）

---

## 一、环境准备

### 1.1 检查 SSH 是否可用

Windows 10/11 自带 OpenSSH，打开 PowerShell 或 CMD 测试：

```powershell
ssh -V
```

**预期输出**：
```
OpenSSH_for_Windows_8.1p1, LibreSSL 3.2.2
```

如果提示"ssh 不是内部或外部命令"，需要手动安装 OpenSSH。

### 1.2 首次连接超算

**重要**：首次连接会提示确认指纹，输入 `yes` 即可。

```powershell
ssh your_hpc_user@swarm01.whu.edu.cn
```

**注意**：
- 输入密码时不会显示任何字符（这是正常的）
- 输完密码直接按回车
- 首次连接会提示 `The authenticity of host...`，输入 `yes` 确认

**连接成功后**：
```
[your_hpc_user@swarm01 ~]$
```

### 1.3 退出超算

```bash
exit
```

或按 `Ctrl + D`

## 二、熟悉超算环境

### 2.1 基本命令

```bash
# 查看当前目录
pwd

# 查看文件
ls -la

# 创建目录
mkdir -p ~/project/CODE/rnn_poetry

# 进入目录
cd ~/project/CODE/rnn_poetry

# 查看磁盘使用
df -h

# 查看当前用户
whoami
```

### 2.2 目录结构

超算的目录结构：

```
~                          # 你的主目录
├── project/               # 项目目录（推荐）
│   └── CODE/              # 代码目录
│       └── rnn_poetry/    # 项目目录
├── scratch/               # 临时目录（定期清理）
└── public/                # 公共目录
```

**重要提醒**：
- `~` 目录空间有限，不要存放大量数据
- `project/` 目录适合存放代码和项目
- `scratch/` 目录适合存放临时数据
- 计算结果要及时下载到本地

### 2.3 环境模块

超算使用模块系统管理软件：

```bash
# 查看可用模块
module avail

# 查看已加载模块
module list

# 加载 Python 模块
module load python/3.8

# 加载 CUDA 模块（GPU计算需要）
module load cuda/11.7

# 卸载模块
module unload python/3.8
```

### 2.4 Python 环境

```bash
# 检查 Python 版本
python3 --version

# 检查 pip
pip3 --version

# 检查 PyTorch
python3 -c "import torch; print(torch.__version__)"

# 检查 CUDA
python3 -c "import torch; print(torch.cuda.is_available())"
```

## 三、上传代码

### 3.1 方法一：使用 scp（推荐）

在本地 PowerShell 中运行：

```powershell
# 1. 先打包项目
cd "d:\Desktop\AI实训\3古诗生成实验\rnn_poetry"
tar -czf rnn_poetry.tar.gz .

# 2. 上传到超算
scp rnn_poetry.tar.gz your_hpc_user@swarm01.whu.edu.cn:~/

# 3. 输入密码
```

**注意**：
- 上传的是压缩包，需要在超算上解压
- 上传时间取决于文件大小和网络速度

### 3.2 方法二：使用 MobaXterm（图形界面）

如果觉得命令行麻烦，可以下载 MobaXterm：

1. 下载 MobaXterm：https://mobaxterm.mobatek.net/download.html
2. 安装后打开，点击 "Session" → "SSH"
3. 填写：
   - Remote host: swarm01.whu.edu.cn
   - Username: your_hpc_user
4. 点击 "OK"，输入密码
5. 左侧文件浏览器可以直接拖拽上传文件

### 3.3 在超算上解压

```bash
# SSH 登录超算
ssh your_hpc_user@swarm01.whu.edu.cn

# 创建项目目录
mkdir -p ~/project/CODE/rnn_poetry
cd ~/project/CODE/rnn_poetry

# 解压代码
tar xzf ~/rnn_poetry.tar.gz

# 删除压缩包
rm ~/rnn_poetry.tar.gz

# 检查文件
ls -la
```

## 九、常见问题

### Q1：连接超算失败

**问题**：`ssh: connect to host swarm01.whu.edu.cn port 22: Connection timed out`

**解决方案**：
1. 检查是否在校园网内
2. 如果不在校园网，需要连接 VPN
3. 联系超算中心确认账号状态

### Q2：密码错误

**问题**：`Permission denied (publickey,gssapi-keyex,gssapi-with-mic,password)`

**解决方案**：
1. 确认用户名正确（your_hpc_user）
2. 确认密码正确（注意大小写）
3. 联系超算中心重置密码

### Q3：磁盘空间不足

**问题**：`No space left on device`

**解决方案**：
```bash
# 查看磁盘使用
df -h

# 清理临时文件
rm -rf /scratch/your_hpc_user/*

# 清理旧的日志
rm -f job_*.log job_*.err
```

### Q4：GPU 不可用

**问题**：`CUDA out of memory` 或 `No CUDA GPUs are available`

**解决方案**：
1. 减小 batch_size：`--batch_size 64`
2. 等待 GPU 资源释放
3. 检查作业是否分配到 GPU 节点

### Q5：训练中断

**问题**：训练过程中作业被取消

**解决方案**：
1. 检查是否超过时间限制
2. 查看错误日志：`cat job_*.err`
3. 调整作业脚本的时间限制

### Q6：模块加载失败

**问题**：`module: command not found`

**解决方案**：
```bash
# 初始化模块系统
source /etc/profile.d/modules.sh

# 或者使用完整路径
/usr/share/Modules/bin/module load python/3.8
```

## 十、作业脚本说明

### 10.1 run_experiments.sh 脚本

```bash
#!/bin/bash
#SBATCH -J rnn_poetry          # 作业名称
#SBATCH -p gpu                 # 分区（gpu/cpu）
#SBATCH -N 1                   # 节点数
#SBATCH --gres=gpu:1           # GPU 数量
#SBATCH -o job_%j.log          # 标准输出文件
#SBATCH -e job_%j.err          # 错误输出文件
#SBATCH --time=10:00:00        # 运行时间限制
```

### 10.2 修改时间限制

如果训练时间不够，可以修改时间限制：

```bash
# 修改脚本
vim run_experiments.sh

# 或者在提交时指定
sbatch --time=20:00:00 run_experiments.sh
```

### 10.3 申请更多 GPU

```bash
# 申请 2 个 GPU
#SBATCH --gres=gpu:2

# 或者提交时指定
sbatch --gres=gpu:2 run_experiments.sh
```

## 十一、安全提醒

### 11.1 不要做的事

- ❌ 不要用 `sudo`（没有权限）
- ❌ 不要在超算上存储敏感信息（密码、密钥等）
- ❌ 不要长时间占用 GPU 资源
- ❌ 不要在超算上运行开发工具（VSCode、RStudio 等）

### 11.2 应该做的事

- ✅ 及时下载重要结果到本地
- ✅ 定期清理临时文件
- ✅ 使用 `--user` 安装 Python 包
- ✅ 遇到问题查看文档或联系管理员

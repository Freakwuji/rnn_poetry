## 二、对照实验设计

### 2.1 有效对照（单一变量）

| 对照组 | 固定因素 | 变量 | 结论 |
|:-------|:---------|:-----|:------|
| **⑦→⑧→③** | 唐诗57K + LSTM + 6487词表 | **轮数** 30→100→200 | 轮数增加，准确率从3.99%增至6.07%，收益递减 |
| **③→④** | LSTM + 200轮 + 6487词表 | **数据** 唐诗57K→多朝138K | 多朝代数据使准确率提升近3倍(6.07%→17.72%) |
| **②→⑦** | 唐诗57K + LSTM + 30轮 | **复现验证** | 3.70%→3.99%，结果可复现 |

### 2.2 无效对照（多重变量）

| 对照组 | 同时变化的因素 | 问题 |
|:-------|:--------------|:-----|
| ①→② | **数据 + 词表** | 无法判断提升来源 |
| ④→⑤ | **模型 + 词表** | 词表从6487降到213，准确率虚高 |
| ⑤→⑥ | **数据 + 轮数 + 早停** | 三个变量不同，无可比性 |

## 三、核心对照链：轮数实验

```
固定变量：唐诗 57,597 首 | LSTM 模型 | 6,487 词表 | Adam 优化器
────────────────────────────────────────────────────────────

准确率
  │
6%╶──────● ③ 200轮 → 6.07%
  │       ↑ 收益递减（+1.53%）
5%╶
  │       ↑ 适量收益（+0.55%）
4%╶──────● ⑧ 100轮 → 4.54%
  │       ↑ 基准
3%╶──● ⑦ 30轮 → 3.99%
  │
  └────────────────────────── 轮数
      30       100       200
```

**分析：**
- 30→100轮：准确率提升 **+0.55%**（每10轮+0.08%）
- 100→200轮：准确率提升 **+1.53%**（每10轮+0.15%）
- 中间段（100-200轮）的学习效率 > 起始段（30-100轮）
- 说明 LSTM 在 100 轮后仍有显著学习能力，200轮仍未完全收敛

## 四、其他对照分析

### 4.1 数据影响（③ vs ④）

```
③ 唐诗 57K → 6.07%
           ↑ +11.65%（数据量增加 2.4 倍）
④ 多朝 138K → 17.72%
```

数据量增加 2.4 倍，准确率提升近 3 倍。但生成质量并未同比提升——多朝数据引入了噪声。

### 4.2 模型影响（无法直接对照）

理想实验设计：

```
固定：唐诗 57K + 30轮 + 6487词表
  LSTM   → ?%     ✅ 实验⑦：3.99%
  LSTM+Attn → ?%  ❌ 缺失
```

Attention 模型的对照实验因代码版本冲突（zip包混淆）未能完成，是当前实验的最大缺口。

## 五、实验设计总结

| 实验数 | 有效对照 | 无效对照 | 缺失对照 |
|:-----:|:--------:|:--------:|:--------|
| 8组 | **4组**（⑦⑧③轮数、③④数据、②⑦复现） | 3组（①②④⑤⑤⑥） | **1组**（LSTM vs LSTM+Attn同条件） |

**核心结论验证程度：**
- ✅ "增加轮数提升准确率"——**已验证**（30→100→200递增）
- ✅ "多朝代数据提升准确率"——**已验证**（唐诗 vs 多朝对比）
- ⚠️ "LSTM优于Attention"——**未严格证明**（缺同条件对照）
- ⚠️ "数据质量大于数量"——**部分证明**（多朝准确率高但生成差）

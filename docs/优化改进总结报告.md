# RNN 古诗词生成项目优化改进总结报告

---

## 一、项目概述

基于 PyTorch 的中国古诗词生成系统，在原 Demo 基础上进行全面优化。

---

## 二、原 Demo 问题分析

| 模块 | 问题 |
|------|------|
| 数据 | 模板拼接，语法不通 |
| 模型 | 基础 LSTM，无 Attention |
| 训练 | StepLR 调度，无早停 |
| 评价 | 只看 Perplexity |

---

## 三、改进内容

### 3.1 数据改进

| 改进项 | 原 Demo | 改进后 |
|--------|---------|--------|
| 数据来源 | 模板拼接 | chinese-poetry 真实数据集 |
| 数据量 | 57k（仅唐诗） | 300k+（唐诗+宋诗） |
| 数据清洗 | 无 | 去重、过滤乱码 |
| 数据类型 | 仅唐诗 | 唐诗+宋诗（只保留五言/七言） |

**为什么只保留诗，不保留词和曲？**

| 类型 | 结构 | 是否保留 | 原因 |
|------|------|----------|------|
| 古诗 | 五言/七言，固定字数 | ✓ | 生成规整 |
| 宋词 | 长短句 | ✗ | 会干扰模型 |
| 元曲 | 长短句 | ✗ | 会干扰模型 |

### 3.2 模型改进

**7个模型对比：**

| # | 模型 | 结构 | 参数量 | 对比目的 |
|---|------|------|--------|----------|
| 1 | LSTM | Embedding→LSTM→Linear | 7.5M | 基线1 |
| 2 | GRU | Embedding→GRU→Linear | 6.6M | 基线2 |
| 3 | LSTM+Attn | Embedding→LSTM→Bahdanau→Linear | 8.6M | 验证Attention |
| 4 | GRU+Attn | Embedding→GRU→Bahdanau→Linear | 7.7M | 对比 |
| 5 | BiLSTM+Attn | Embedding→BiLSTM→Bahdanau→Linear | 16.2M | 验证双向 |
| 6 | LSTM+MultiAttn | Embedding→LSTM→MultiHead→Linear | 8.8M | 验证多头 |
| 7 | BiLSTM+MultiAttn | Embedding→BiLSTM→MultiHead→Linear | 18.3M | 完整版 |

**对比逻辑：**
```
1 vs 2: LSTM vs GRU
1 vs 3: 验证Attention效果
3 vs 4: LSTM+Attn vs GRU+Attn
3 vs 5: 验证双向效果
3 vs 6: 验证多头效果
1 vs 7: 完整改进效果
```

### 3.3 训练改进

| 改进项 | 原 Demo | 改进后 |
|--------|---------|--------|
| 学习率调度 | StepLR | Warmup + CosineAnnealing |
| 早停 | 无 | 早停（耐心15轮） |
| 混合精度 | 无 | AMP |
| 采样策略 | 简单采样 | Top-K + Top-P + 重复惩罚 |

### 3.4 评价改进

| 评价方式 | 指标 | 说明 |
|----------|------|------|
| 自动指标 | Perplexity, BLEU | 客观指标 |
| 规则化评价 | 押韵、对仗、重复度、字数、意象 | 结构评价 |
| 人工评价 | 通顺度、意境、押韵、创意 | 主观评价 |
| AI评价 | 多维度打分 | 综合评价 |

## 八、总结

本次改进从数据、模型、训练、评价四个维度全面优化了原 Demo：

1. **数据改进**：
   - 使用 chinese-poetry 真实数据集（30万+首）
   - 只保留唐诗和宋诗（五言/七言），不保留宋词和元曲
   - 数据清洗：去重、过滤乱码

2. **模型改进**：
   - 7个模型对比，验证每个组件的效果
   - LSTM vs GRU：验证哪个基础模型更好
   - Attention：验证是否有效
   - 双向LSTM：验证是否更好
   - 多头Attention：验证是否更好

3. **训练改进**：
   - Warmup + CosineAnnealing 学习率调度
   - 早停机制
   - 混合精度训练（AMP）
   - Top-K + Top-P + 重复惩罚

4. **评价改进**：
   - 多角度评价体系
   - 自动指标：Perplexity、BLEU
   - 规则化评价：押韵、对仗、重复度、字数、意象
   - 人工评价：通顺度、意境、押韵、创意
   - AI评价：多维度打分

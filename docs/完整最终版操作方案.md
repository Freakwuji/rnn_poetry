## 四、训练模型

### 4.1 单模型训练

```bash
python main.py --train --model lstm_attn --epochs 200 --use_amp
```

### 4.2 对比实验

```bash
python main.py --compare --epochs 200 --use_amp
```

**对比的7个模型：**

| 模型 | 结构 | 参数量 | 对比目的 |
|------|------|--------|----------|
| LSTM | 基础LSTM | ~7.5M | 基线1 |
| GRU | 基础GRU | ~6.6M | 基线2 |
| LSTM+Attn | LSTM + Bahdanau | ~8.6M | 验证Attention |
| GRU+Attn | GRU + Bahdanau | ~7.7M | 对比 |
| BiLSTM+Attn | 双向LSTM + Bahdanau | ~16.2M | 验证双向 |
| LSTM+MultiAttn | LSTM + MultiHead | ~8.8M | 验证多头 |
| BiLSTM+MultiAttn | 双向LSTM + MultiHead | ~18.3M | 完整版 |

### 4.3 生成古诗

```bash

```

## 六、评价系统

### 6.1 规则化评价

```python
from evaluate import RuleBasedEvaluator

evaluator = RuleBasedEvaluator()
score, details = evaluator.evaluate_poem("春江水暖鸭先知")
print(f"得分: {score:.3f}")
```

**评价维度：**

| 维度 | 权重 | 检测方法 |
|------|------|----------|
| 押韵 | 25% | 检查句尾韵母 |
| 对仗 | 20% | 检查字数整齐度 |
| 重复度 | 20% | 计算重复率 |
| 字数整齐 | 15% | 是否五言/七言 |
| 意象丰富 | 20% | 检查意象词汇 |

### 6.2 BLEU 评价

```python
from evaluate import AutomaticEvaluator

evaluator = AutomaticEvaluator()
bleu = evaluator.calculate_bleu("春江水暖鸭先知", "春江水暖鸭先知")
print(f"BLEU: {bleu:.3f}")
```

### 6.3 AI 评价

```python
from evaluate import AIEvaluator

evaluator = AIEvaluator()
score = evaluator.evaluate_locally("春江水暖鸭先知", "春江")
print(f"通顺度: {score['通顺度']}")
print(f"意境: {score['意境']}")
print(f"押韵: {score['押韵']}")
print(f"创意: {score['创意']}")
print(f"总分: {score['总分']}")
```

### 6.4 生成评价表

```python
from evaluate import ComprehensiveEvaluator

evaluator = ComprehensiveEvaluator()
evaluator.human_evaluator.generate_evaluation_table(
    poems=[
        ('LSTM', '春江', '春江水暖鸭先知'),
        ('LSTM+Attn', '春江', '春江潮水连海平'),
    ],
    output_file='evaluation_table.md'
)
```

## 九、常见问题

### Q1：测试失败

**问题**：`ModuleNotFoundError`

**解决**：`pip install torch numpy matplotlib`

### Q2：超算 CUDA 不可用

**问题**：`CUDA: False`

**解决**：登录节点没有GPU，提交作业后就有GPU了。

### Q3：训练太慢

**解决**：
1. 确保使用了GPU
2. 确保 `--use_amp`
3. 减小 `--batch_size 64`

### Q4：生成质量差

**解决**：
1. 增加训练轮数
2. 调整 `--temperature 0.6`
3. 调整 `--top_k 10`

### Q5：可视化图表显示中文

**问题**：图表中文显示为方块

**解决**：安装中文字体
```bash
# Windows
# 通常已有SimHei字体

# Linux
sudo apt-get install fonts-wqy-zenhei
```

# RNN 古诗词生成 — 模型原理

---

## 一、任务定义

古诗词生成本质上是一个 **字符级语言模型（Character-level Language Model）**：

> 给定前 n-1 个字，预测第 n 个字是什么。

```
输入: "床前明"  →  模型预测下一个字 → "月"
输入: "床前明月"  →  模型预测下一个字 → "光"
输入: "床前明月光" → 模型预测下一个字 → "。"
```

把一句话拆成大量这样的"前一字→后一字"训练样本，模型就能学会唐诗的用字规律。

---

## 二、模型结构总览

```
输入: "床前明"（三个字的索引 [3, 5, 7]）
    │
    ▼
Embedding Layer（词嵌入层）
    把离散的字索引转为稠密向量
    [3, 5, 7] → [[0.2, -0.1, ...], [0.5, 0.3, ...], [-0.1, 0.8, ...]]
    │
    ▼
LSTM Layer（循环神经网络层）
    逐个处理每个字，同时记住"历史信息"
    看到"床"→记住; 看到"前"→结合"床"的上下文; 看到"明"→结合"床前"的上下文
    │
    ▼
Dropout Layer（正则化层）
    随机丢弃 50% 的神经元，防止过拟合
    │
    ▼
Linear Layer（全连接层）
    将 LSTM 的隐藏状态映射到词表大小的分数向量
    [0.1, 0.5, -0.3, 2.1, ...]  ← 6487 维，每个维度对应一个字
    │
    ▼
Softmax（训练时） / Top-k 采样（生成时）
    → 输出概率最高的字
```

---

## 三、各层详解

### 3.1 Embedding Layer（词嵌入层）

**问题**：计算机不能直接理解汉字"床"。它只能处理数字。

**解决**：每个汉字映射到一个 256 维的向量。

```
"床" → [0.2, -0.5, 0.8, 0.1, -0.3, 0.6, ...]  (256 个浮点数)
"前" → [0.7, 0.1, -0.3, 0.5, 0.2, -0.8, ...]
"明" → [0.4, 0.3, -0.6, -0.2, 0.9, 0.1, ...]
```

**关键性质**：含义相近的字，向量距离也近。

```
"江" → [0.3, 0.7, ...]
"河" → [0.4, 0.6, ...]  ← 和"江"的向量很接近（都是水体）
"山" → [-0.5, 0.2, ...]  ← 和"江"的向量较远（山水不同类）
```

这个映射不是人工设计的——**是模型在训练中自己学出来的**。

### 3.2 LSTM Layer（长短期记忆网络）

#### RNN 的核心思想

传统的神经网络（如 CNN）不能处理序列数据——它们假设输入是独立的。但文字是**有先后顺序的**：

```
"床" → "前" → "明" → "月" → "光"
 每个字的理解都依赖前面的字
```

RNN（循环神经网络）的核心：**维护一个"隐藏状态" h，每读一个字就更新一次 h。**

```
初始: h₀ = [0, 0, ..., 0]  (256 维零向量)

读"床": h₁ = f(h₀, "床")  → 记住了"看了一个字：床"
读"前": h₂ = f(h₁, "前")  → 记住了"看了两个字：床前"
读"明": h₃ = f(h₂, "明")  → 记住了"看了三个字：床前明"
...
```

**隐藏状态 h 就是模型对已读内容的"理解"或"记忆"。**

#### RNN 的缺陷

简单 RNN 记不住太久远的内容：

```
"我从小学就开始学习唐诗宋词，到现在已经背了三百多首，其中最喜..."
  ↑                                                       ↑
 当模型读到"喜"时，前面的"小学"信息已经被冲淡了
```

原因：梯度消失——反向传播时，每往前传一层，梯度指数级衰减，最终前面的信息根本传不回来。

#### LSTM 的改进

LSTM（Long Short-Term Memory）通过**三个门**来控制信息的流动：

```
┌─────────────────────────────────────────────────────┐
│                      LSTM 单元                        │
│                                                       │
│   遗忘门       输入门         输出门                   │
│   ┌────┐     ┌────┐        ┌────┐                     │
│   │ ×  │     │ +  │        │ ×  │                     │
│   └─┬──┘     └─┬──┘        └─┬──┘                     │
│     │          │              │                         │
│  ┌──▼──┐   ┌──▼──┐       ┌──▼──┐                      │
│  │sigmoid│  │sigmoid│      │sigmoid│  tanh              │
│  └──┬──┘   └──┬──┘       └──┬──┘                        │
│     │         │              │                          │
│     hₜ₋₁      xₜ             hₜ₋₁                      │
│                                                         │
│  细胞状态 Cₜ₋₁ ──────→ Cₜ                               │
│  隐藏状态 hₜ₋₁ ──────→ hₜ                               │
└─────────────────────────────────────────────────────┘
```

**三个门的通俗解释：**

| 门 | 作用 | 类比 |
|:--:|:-----|:-----|
| **遗忘门** | 决定"忘掉什么" | 你读完前一句，决定忘掉不重要的细节 |
| **输入门** | 决定"记住什么新信息" | 你读到新句子，选择性地记住关键内容 |
| **输出门** | 决定"输出什么" | 综合所有记忆，决定输出那个字 |

**LSTM 的威力**：可以记住 100+ 字之前的内容，对诗词生成至关重要——一首五言诗 20 个字，LSTM 能从头到尾保持连贯。

### 3.3 Dropout Layer

**问题**：模型参数太多（3.8M），容易过拟合——把训练集的"噪声"也记住了。

**解决**：训练时随机丢弃 50% 的神经元。

```
训练时:                   测试时:
  ● ─ ● ─ ●               ● ─ ● ─ ●
  │   │   │               │   │   │
  ✗ ─ ● ─ ✗     →         ● ─ ● ─ ●   ← 全部保留
  │   │   │               │   │   │
  ● ─ ✗ ─ ●
  50% 神经元被关掉         所有神经元都工作
```

**效果**：模型不能依赖任何一个特定的"专家"神经元，每个神经元都必须学到有用的东西 → **泛化能力更强**。

### 3.4 Linear Layer（全连接层）

LSTM 的输出是 512 维的隐藏向量。我们需要把它映射到词表大小（6487 维），每个维度对应一个字的"得分"。

```
LSTM 输出: [0.3, -0.1, 0.8, ..., 0.2]  (512 维)
    │
    ▼ Linear(512 → 6487)
    │
    ▼
得分向量: [-2.1, 0.5, 0.3, 3.2, -1.8, ..., 0.7]  (6487 维)
              ↑
        第 4 维得分最高 → 词表中第 4 个字就是"月"
```

## 四、训练过程

### 4.1 损失函数

使用 **CrossEntropyLoss（交叉熵损失）**：

```
loss = -log(softmax(score)[correct_index])

例子：
  模型输出分数: [0.2, 1.5, 0.8, 3.1, ...] 
  正确答案 idx: 3（"月"字索引）
  
  softmax 后第 3 维概率: 0.7
  loss = -log(0.7) = 0.36
  
  模型越准 → 概率越接近 1 → loss 越接近 0
  模型越错 → 概率越接近 0 → loss 越接近 ∞
```

### 4.2 优化器

使用 **Adam** + 余弦退火学习率调度：

```python
optimizer = optim.Adam(model.parameters(), lr=0.001)
scheduler = CosineAnnealingLR(optimizer, T_max=200)
```

学习率从 0.001 按余弦曲线逐渐衰减到接近 0——前期大步探索，后期小步精调。

### 4.3 梯度裁剪

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=5.0)
```

防止梯度爆炸（RNN 的常见问题——梯度在多层时间步中累积，可能变得极大）。

## 五、生成过程

### 5.1 训练 vs 生成

```
训练时（Teac her Forcing）:
  输入: "床前明" → 模型预测 → 目标: "月"
  输入: "前明月" → 模型预测 → 目标: "光"
  每一步都用"正确答案"作为输入

生成时（Autoregressive）:
  输入: "春" → 模型预测 → "江"
  输入: "春江" → 模型预测 → "水"  ← 用自己预测的结果作为输入
  输入: "春江水" → 模型预测 → ...
```

### 5.2 Top-k 采样

不是每次都选概率最高的字（那样会太死板），而是：

```python
# 1. 只保留概率最高的 k 个字
# 2. 重新计算这 k 个字的概率（和为 1）
# 3. 按概率随机采样

例如 k=5:
  候选: [月(0.6), 水(0.2), 风(0.1), 山(0.07), 云(0.03)]
  按概率随机选 → 60% 概率选"月"，20% 概率选"水"...
```

### 5.3 温度调节

```python
logits = logits / temperature   # 温度缩放

t=0.5:      t=0.8:       t=1.2:
  更保守      平衡        更随机
  选概率       推荐值      可能跳出常规
  最高的字
```

## 六、LSTM vs Transformer

既然已经有了更先进的 Transformer 架构，为什么还在用 LSTM？

| 对比项 | LSTM | Transformer |
|:------|:-----|:------------|
| 参数量 | 3.8M | 通常 100M+ |
| 训练速度（CPU） | 15s/epoch | 数小时 |
| 训练速度（GPU） | 快 | 仍需较长时间 |
| 长文本能力 | 100+ 字 | 无限 |
| 古诗生成 | ✅ 足够用 | 性能过剩 |
| 资源需求 | 低 | 高 |

**结论**：对于古诗词生成这种中等长度（20-60 字）、有限词表（6487 字）的任务，LSTM 在效果和效率之间达到了最佳平衡。

## 七、完整数据流示例

```
输入: "春江" → 模型要生成后续诗句

第 1 步:
  Embedding("春") → [0.2, -0.1, ...] (256维)
  Embedding("江") → [0.5, 0.3, ...]
  LSTM([春向量, 江向量]) → h = [0.3, -0.5, ..., 0.7] (512维)
  Linear(h) → Score[6487]
  Top-k(Score) → "水" (概率最高)

第 2 步:
  输入变为 "春江水"
  LSTM([春,江,水]) → h_new
  Linear(h_new) → Score
  Top-k(Score) → "暖"
  
  依此类推，直到生成长度达到要求
```

**这就是整个模型的核心原理——一个字一个字地生成，每个字都基于前文内容。**

### 2.4 构建词表 (`build_vocab`)

**什么是词表？**

把汉字转换成数字，模型才能处理：

```
字 → 数字
床 → 100
前 → 200
明 → 300
月 → 400
光 → 500
```

```python
def build_vocab(poems, min_freq=2):
    """
    做了什么：
    1. 统计每个字出现的次数
    2. 过滤掉出现次数少于2次的字
    3. 给每个字分配一个数字编号
    
    输入: ['床前明月光', '疑是地上霜', ...]
    输出: 词表字典
    """
    # 统计字频
    counter = Counter()
    for poem in poems:
        counter.update(poem)  # '床前明月光' → {'床':1, '前':1, '明':1, ...}
    
    # 过滤低频字
    vocab_words = [w for w, c in counter.items() if c >= 2]
    
    # 构建映射
    word2idx = {'<PAD>': 0, '<UNK>': 1, '<SOS>': 2, '<EOS>': 3}
    for i, word in enumerate(vocab_words):
        word2idx[word] = i + 4
    
    return vocab
```

### 3.2 基础 LSTM (`PoetryLSTM`)

```
输入: [床, 前, 明, 月] (4个字的索引)
     ↓
Embedding层: 把每个字变成向量
[0.2, -0.5, 0.8, ...] → 256维向量
     ↓
LSTM层: 提取时序特征
隐藏状态: 记住前面看过的内容
     ↓
Linear层: 映射到词表大小
输出: 每个字的概率分布
```

```python
class PoetryLSTM(nn.Module):
    def __init__(self, vocab_size, embedding_dim=256, hidden_dim=512):
        # 词嵌入: 把字索引变成向量
        # 输入: [batch, seq_len] → 输出: [batch, seq_len, 256]
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        
        # LSTM层: 提取时序特征
        # 输入: [batch, seq_len, 256] → 输出: [batch, seq_len, 512]
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, num_layers=2)
        
        # 输出层: 映射到词表
        # 输入: [batch, seq_len, 512] → 输出: [batch, seq_len, vocab_size]
        self.fc = nn.Linear(hidden_dim, vocab_size)
    
    def forward(self, x):
        x = self.embedding(x)      # 字索引 → 向量
        x, hidden = self.lstm(x)   # LSTM处理
        x = self.fc(x)             # 映射到词表
        return x, hidden
```

### 3.3 基础 GRU (`PoetryGRU`)

**GRU vs LSTM**：
- GRU 只有 2 个门（重置门、更新门）
- LSTM 有 3 个门（遗忘门、输入门、输出门）
- GRU 参数更少，训练更快

```python
class PoetryGRU(nn.Module):
    def __init__(self, vocab_size, embedding_dim=256, hidden_dim=512):
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.gru = nn.GRU(embedding_dim, hidden_dim, num_layers=2)
        self.fc = nn.Linear(hidden_dim, vocab_size)
    
    def forward(self, x):
        x = self.embedding(x)
        x, hidden = self.gru(x)
        x = self.fc(x)
        return x, hidden
```

### 3.4 LSTM + Attention (`PoetryLSTMAttention`)

**Attention 的作用**：

基础LSTM只用最后一个时间步的输出，丢失了前面的信息。

Attention让模型在生成每个字时，能"回头看"前面所有位置：

```
生成"月"字时：
  当前状态: 月
  前面有: 床、前、明
  Attention权重: 床(0.1), 前(0.2), 明(0.7)
  
  → 模型重点关注"明"，因为"明月"是常见搭配
```

```python
class PoetryLSTMAttention(nn.Module):
    def __init__(self, vocab_size, embedding_dim=256, hidden_dim=512):
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, num_layers=2)
        self.attention = BahdanauAttention(hidden_dim)  # 新增
        self.fc = nn.Linear(hidden_dim * 2, hidden_dim)  # 注意这里是*2
        self.output = nn.Linear(hidden_dim, vocab_size)
    
    def forward(self, x):
        # 1. Embedding
        embedded = self.embedding(x)
        
        # 2. LSTM
        lstm_out, hidden = self.lstm(embedded)
        
        # 3. Attention (对每个时间步)
        outputs = []
        for t in range(seq_len):
            query = lstm_out[:, t:t+1, :]      # 当前位置
            context, weights = self.attention(query, lstm_out)  # 计算注意力
            combined = torch.cat([context, query], dim=-1)      # 拼接
            outputs.append(combined)
        
        # 4. 输出层
        outputs = torch.cat(outputs, dim=1)
        logits = self.output(self.fc(outputs))
        
        return logits, hidden
```

```python
class PoetryBiLSTMAttention(nn.Module):

        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        
        # 双向 LSTM
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, num_layers=2, 
                           bidirectional=True)
        
        # Attention（双向的 hidden_dim * 2）
        self.attention = BahdanauAttention(hidden_dim * 2)
        
        # 投影层：将双向映射到单向
        self.projection = nn.Linear(hidden_dim * 2, hidden_dim)
        
        self.fc = nn.Linear(hidden_dim, hidden_dim)
        self.output = nn.Linear(hidden_dim, vocab_size)
```

## 四、Attention 机制 (attention.py)

### 4.1 Bahdanau Attention

**核心思想**：计算当前状态和所有历史状态的相关性

```python
class BahdanauAttention(nn.Module):
    def forward(self, query, keys):
        """
        query: 当前时间步 [batch, 1, hidden]
        keys: 所有时间步 [batch, seq_len, hidden]
        
        计算过程：
        1. query和keys分别做线性变换
        2. 相加后通过tanh
        3. 再做线性变换得到分数
        4. softmax归一化得到权重
        5. 用权重对keys加权求和
        """
        # 线性变换
        query_transformed = self.Wa(query)  # [batch, 1, hidden]
        keys_transformed = self.Ua(keys)    # [batch, seq_len, hidden]
        
        # 相加 + tanh + 映射到标量
        combined = query_transformed + keys_transformed
        scores = self.va(torch.tanh(combined))  # [batch, seq_len, 1]
        
        # 归一化
        weights = F.softmax(scores, dim=1)  # [batch, seq_len, 1]
        
        # 加权求和
        context = torch.bmm(weights.transpose(1, 2), keys)  # [batch, 1, hidden]
        
        return context, weights
```

### 4.2 MultiHead Attention

**优势**：多个头同时关注不同位置

```python
class MultiHeadAttention(nn.Module):
    def forward(self, query, keys, mask=None):
        # 线性变换
        Q = self.Wq(query).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        K = self.Wk(keys).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        V = self.Wv(keys).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        
        # 计算注意力
        scores = torch.matmul(Q, K.transpose(-2, -1)) / (self.head_dim ** 0.5)
        weights = F.softmax(scores, dim=-1)
        context = torch.matmul(weights, V)
        
        # 合并多头
        context = context.transpose(1, 2).contiguous().view(batch_size, -1, self.num_heads * self.head_dim)
        output = self.Wo(context)
        
        return output, weights.mean(dim=1)
```

### 5.1 训练流程


### 5.2 Warmup + CosineAnnealing

**为什么用这个调度器？**

```
学习率变化：
Epoch 1-5:   0.0002 → 0.001 (Warmup，线性增加)
Epoch 6-200: 0.001 → 0.00001 (Cosine，余弦衰减)
```

- Warmup：避免初期梯度不稳定
- Cosine：比StepLR更平滑

```python
class WarmupCosineScheduler:
    def step(self):
        if self.current_epoch <= self.warmup_epochs:
            # Warmup: 线性增加
            lr = self.max_lr * (self.current_epoch / self.warmup_epochs)
        else:
            # Cosine: 余弦衰减
            progress = (self.current_epoch - self.warmup_epochs) / self.total_epochs
            lr = self.min_lr + (self.max_lr - self.min_lr) * 0.5 * (1 + cos(progress * π))
        
        # 更新学习率
        for param_group in self.optimizer.param_groups:
            param_group['lr'] = lr
```

### 5.3 早停机制

**为什么需要早停？**

训练太久会过拟合：模型记住训练集，但生成质量下降。

```python
class EarlyStopping:
    def __call__(self, val_loss, epoch, model, save_path):
        if val_loss > self.best_loss - self.min_delta:
            # 没有改善，计数+1
            self.counter += 1
            if self.counter >= self.patience:  # 连续15轮不下降
                self.early_stop = True  # 停止训练
        else:
            # 有改善，保存模型，重置计数
            self.best_loss = val_loss
            self.save_checkpoint(val_loss, epoch, model, save_path)
            self.counter = 0
        
        return self.early_stop
```

## 六、评价系统 (evaluate.py)

### 6.1 为什么不能只看 Perplexity？

Perplexity（困惑度）= exp(loss)

**问题**：
- 低Perplexity只说明模型"不困惑"，不代表生成的诗有诗意
- 模型可能只是学会了常见搭配，没有创造性
- 需要多角度评价

### 6.2 规则化评价

**5个评价维度**：

| 维度 | 权重 | 检测方法 |
|------|------|----------|
| 押韵 | 25% | 检查句尾字的韵母是否相同 |
| 对仗 | 20% | 检查字数是否整齐 |
| 重复度 | 20% | 计算字符和2-gram重复率 |
| 字数整齐 | 15% | 是否为标准五言或七言 |
| 意象丰富 | 20% | 是否包含常见古诗意象 |

### 6.3 BLEU 评价

BLEU 衡量生成文本和参考文本的 n-gram 重叠度。

```python
def calculate_bleu(self, generated, reference, n=4):
    """
    计算 BLEU 分数
    
    值范围 [0, 1]，越高越好
    """
    def get_ngrams(text, n):
        return [text[i:i+n] for i in range(len(text)-n+1)]
    
    # 计算各阶 BLEU
    scores = []
    for i in range(1, n+1):
        gen_ngrams = get_ngrams(generated, i)
        ref_ngrams = get_ngrams(reference, i)
        
        # 计算匹配数
        ref_counter = Counter(ref_ngrams)
        gen_counter = Counter(gen_ngrams)
        
        matches = sum(min(count, ref_counter.get(ngram, 0)) 
                     for ngram, count in gen_counter.items())
        
        precision = matches / len(gen_ngrams) if gen_ngrams else 0
        scores.append(precision)
    
    # 几何平均 + 简短惩罚
    if min(scores) > 0:
        bleu = math.exp(sum(math.log(s) for s in scores) / len(scores))
    else:
        bleu = 0
    
    return bleu * min(1, len(generated) / max(len(reference), 1))
```

```python
class AIEvaluator:
    def evaluate_locally(self, poem, start_word=''):
        """
        本地规则化评价（不需要大模型）
        
        根据诗句的特征自动打分
        """
        # 通顺度：检查常见字比例
        common_chars = set('的一是了不在有我他这中大来上个人到说')
        common_ratio = sum(1 for c in chars if c in common_chars) / len(chars)
        smoothness = min(10, int(common_ratio * 15))
        
        # 意境：检查意象词汇
        imagery_words = {'月': 2, '花': 2, '水': 1, '山': 1, '风': 1}
        imagery_score = sum(imagery_words.get(c, 0) for c in chars)
        imagery = min(10, int(imagery_score * 1.5) + 3)
        
        # 押韵：检查句尾韵母
        rhyme = self._check_rhyme(poem)
        
        # 创意：基于重复度
        unique_ratio = len(set(chars)) / len(chars)
        creativity = min(10, int(unique_ratio * 12) + 2)
        
        return {
            '通顺度': smoothness,
            '意境': imagery,
            '押韵': rhyme,
            '创意': creativity,
            '总分': (smoothness + imagery + rhyme + creativity) / 4
        }
```

```python
        temperature: 温度（越高越随机）
        top_k: top-k 采样
        top_p: nucleus 采样
        repetition_penalty: 重复惩罚
    """
    for _ in range(max_len):
        logits, hidden = model(current, hidden)
        
        # 1. 温度调整
        logits = logits / temperature
        
        # 2. 重复惩罚
        for idx in set(generated_indices):
            if logits[0, idx] > 0:
                logits[0, idx] /= repetition_penalty
        
        # 3. Top-K 采样
        if top_k > 0:
            values, _ = torch.topk(logits, top_k)
            logits[logits < values[:, -1:]] = float('-inf')
        
        # 4. Top-P 采样
        if top_p < 1.0:
            sorted_logits, sorted_indices = torch.sort(logits, descending=True)
            cumulative_probs = torch.cumsum(torch.softmax(sorted_logits, dim=-1), dim=-1)
            sorted_indices_to_remove = cumulative_probs > top_p
            ...
        
        # 5. 采样
        probs = torch.softmax(logits, dim=-1)
        next_idx = torch.multinomial(probs, 1).item()
```
